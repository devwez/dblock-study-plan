# D Block Study Plan — November 2026

A single-page study dashboard for the D Block November 2026 exams.

- Five subjects: Mathematics, English, isiZulu, Information Technology, Music.
- Two hours a day, two subjects a day, two sections per subject.
- Every day from 26 October to 26 November, with the six exam dates.
- Ticks and notes are saved in the browser (localStorage).
- Target average: 90%.

Open index.html or the GitHub Pages URL. No build step, no dependencies.
